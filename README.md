# Live Translator — 실시간 번역 자막

검은 화면에 실시간 번역 자막만 띄우는 무료 웹앱. **말한 언어를 자동으로 알아내서** 다른 쪽 언어로 번역한다 (예: 영어로 말하면 한국어로, 한국어로 말하면 영어로).

## 실행

**바로 쓰기 (PC·휴대폰)**: https://arnold6444.github.io/live-translator/

**PC 로컬**

```bash
node serve.js
```

크롬으로 http://localhost:5173 을 연다. (끄기: 터미널에서 Ctrl+C)

> 마이크는 `https://` 또는 `localhost`에서만 동작한다. 같은 와이파이에서 `http://PC-IP:5173`으로 열면 마이크가 막힌다.

## 음성인식 엔진 (설정 바 두 번째 칸)

| 엔진 | 언어 | 속도·크기 | 비고 |
|---|---|---|---|
| **자동 감지 · 빠름** (기본) | 자동 판별 | 말하는 중 글자 미리보기, 번역은 말 끝나고 약 1.5~3초. 처음 한 번 약 90MB 내려받기 | Whisper base, 기기 안에서 실행(무료) |
| 자동 감지 · 정확 | 자동 판별 | 문장당 2~3초 더, 약 320MB | Whisper small, 한국어가 더 정확. PC 권장 |
| 언어 고정 · 크롬 | 미리 정한 언어만 | 말하는 중에도 글자가 바로 뜸 | 크롬 음성인식. 대화 모드에서 버튼/Space로 화자 전환 |

- 자동 감지는 '상대 언어'와 '내 언어' 두 개 중 어느 쪽인지 **소리로** 판별한다. 그래서 두 언어를 맞게 골라 두어야 한다.
- 말하는 중에는 받아 적은 글자가 흐리게 먼저 뜨고, 말이 0.5초 끊기면 문장을 확정해 번역한다. 12초 넘게 이어지면 중간에 자른다. (기기가 느리면 미리보기는 자동으로 꺼짐)
- 음성 모델은 브라우저에 저장된다. 두 번째부터는 페이지를 열면 몇 초 안에 미리 불러와서 ▶ 시작을 누르면 바로 듣는다.

## 모드

| 모드 | 어디서 | 소리 |
|---|---|---|
| 통화 | PC | PC 소리(상대) + 마이크(나). 시작 → 공유 창에서 통화 창(또는 전체 화면) + **'오디오 공유' 켜기**. 헤드폰 권장 |
| 듣기 | PC·휴대폰 | 마이크 또는 PC 소리 (컨퍼런스·발표·영상) |
| 대화 | PC·휴대폰 | 마이크 하나 (마주 보고 대화) |

- 줌·팀즈 **데스크톱 앱**이면 공유 창에서 '전체 화면' + '시스템 오디오 공유'. 웹(구글밋 등)이면 그 탭 + '탭 오디오도 공유'.
- 언어 고정 엔진의 통화 모드에서 크롬이 두 소리를 동시에 못 받으면 **"Space 누르고 있는 동안 내 말"** 방식으로 바뀐다.

## 아이폰

- 자동 감지 엔진: 사파리 권장 (iOS 26 이상이면 GPU로 빨라짐). 처음 시작할 때 마이크 허용.
- 언어 고정 엔진: **사파리에서만** 된다 (아이폰 크롬·카톡 등 앱 안 브라우저는 애플 정책상 불가). 오류가 나면 설정 > 일반 > 키보드 > **받아쓰기 활성화**.
- 듣기가 끊기면 화면에 **"▶ 탭해서 계속 듣기"**가 뜬다 → 화면 아무 데나 한 번 탭.

## 화면 조작

평소엔 자막만 보이고, 마우스를 움직이거나 화면을 탭하면 위에 설정 바가 3초간 뜬다.

| 키 | 동작 |
|---|---|
| `S` | 시작 / 정지 |
| `Space` | (언어 고정) 대화: 화자 전환 · 통화 대체 방식: 누르는 동안 내 말 |
| `F` | 전체화면 |
| `+` / `-` | 글자 크기 |

설정(엔진, 모드, 언어, 글자 크기, 원문 표시)은 브라우저에 저장된다.

## 번역

- PC 크롬(138+): **기기 내 번역**(Translator API). 첫 시작 때 언어 모델을 내려받고, 그동안은 온라인 번역을 쓴다.
- 휴대폰·그 외: 무료 온라인 번역. 구글 무료 주소 2곳 → MyMemory 순서로 시도하고, '요청 너무 많음(429)'으로 막힌 곳은 30분 쉬었다가 다시 쓴다.
- PC 크롬에서는 말하는 중 미리보기도 기기 안에서 번역된다. 온라인 번역은 막힘을 피하려고 문장이 끝날 때만 부른다.

## 언어 추가

`app.js` 맨 위 `LANGS`에 한 줄 추가: `{ id: 'nl', name: 'Nederlands', stt: 'nl-NL' }`

## 직접 테스트 체크리스트

- [ ] PC 크롬 · 대화 · 자동 감지: 영어로 말하면 한국어 자막(왼쪽), 한국어로 말하면 영어 자막(오른쪽)
- [ ] 아이폰 사파리 · 대화 · 자동 감지: 모델 내려받기(%) 후 같은 결과, 화면이 꺼지지 않음
- [ ] PC 크롬 · 듣기 · PC 소리: 유튜브 영어 영상 탭을 공유하면 자막이 뜬다
- [ ] PC 크롬 · 통화: 상대와 내 말이 각각 번역된다

## 데모

`http://localhost:5173/?demo=1` — 마이크 없이 예문으로 화면과 번역을 확인.

## 한계

- 통화 모드·PC 소리는 PC 크롬 전용 (휴대폰 브라우저는 다른 앱 소리를 못 받음).
- 스피커로 들으면 마이크가 상대 소리까지 받을 수 있다 → 헤드폰 권장.
- 자동 감지의 번역은 문장이 끝나야 뜬다 (말하는 중엔 원문 미리보기만, PC 크롬은 번역 미리보기도).
- '빠름' 모델은 한국어 받아쓰기가 가끔 틀린다 → '정확' 모델로 바꾸면 나아짐 (대신 느림).
- 무료 온라인 번역은 비공식이라 막히거나 느려질 수 있다.
