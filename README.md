# Live Translator — 실시간 번역 자막

검은 화면에 실시간 번역 자막만 띄우는 웹앱. 무료(크롬 내장 음성인식 + 크롬 내장 번역, 안 되면 무료 온라인 번역).

## 실행

**PC (로컬)**

```bash
node serve.js
```

크롬으로 http://localhost:5173 을 연다. (끄기: 터미널에서 Ctrl+C)

**모바일 / 어디서나**: https://arnold6444.github.io/live-translator/

> 마이크는 `https://` 또는 `localhost`에서만 동작한다. 같은 와이파이에서 `http://PC-IP:5173`으로 열면 마이크가 막힌다.

**아이폰**

- **사파리로 열어야 한다.** 아이폰 크롬·카톡 등 앱 안 브라우저는 애플 정책상 음성인식이 안 된다.
- 처음 시작할 때 마이크·음성 인식 허용을 누른다. 오류가 나면: 설정 > 일반 > 키보드 > **받아쓰기 활성화** 켜기, 설정 > 앱 > Safari > 마이크 **허용**.
- 사파리가 듣기를 끊으면 화면에 **"▶ 탭해서 계속 듣기"**가 뜬다 → 화면 아무 데나 한 번 탭.

## 모드

| 모드 | 어디서 | 소리 | 쓰는 법 |
|---|---|---|---|
| 통화 | PC | 상대 = PC 소리, 나 = 마이크 | 시작 → 공유 창에서 통화 창(또는 전체 화면) 선택 + **'오디오 공유' 켜기**. 헤드폰 권장 |
| 듣기 | PC·모바일 | 마이크 또는 PC 소리 | 컨퍼런스·발표·영상. 상대 언어 → 내 언어 한 방향 |
| 대화 | PC·모바일 | 마이크 하나 | 아래 버튼(또는 Space)으로 말하는 사람 전환 |

- 통화 모드에서 크롬이 두 소리를 동시에 못 받으면 자동으로 **"Space 누르고 있는 동안 내 말"** 방식으로 바뀐다.
- 줌·팀즈 **데스크톱 앱**이면 공유 창에서 '전체 화면' + '시스템 오디오 공유'를 고른다. 웹(구글밋 등)이면 그 탭 + '탭 오디오도 공유'.

## 화면 조작

평소엔 자막만 보이고, 마우스를 움직이거나 화면을 탭하면 위에 설정 바가 3초간 뜬다.

| 키 | 동작 |
|---|---|
| `S` | 시작 / 정지 |
| `Space` | 대화: 화자 전환 · 통화(대체 방식): 누르는 동안 내 말 |
| `F` | 전체화면 |
| `+` / `-` | 글자 크기 |

설정(모드, 언어, 글자 크기, 원문 표시)은 브라우저에 저장된다.

## 번역 엔진

- PC 크롬(138+): **기기 내 번역**(Translator API). 첫 시작 때 언어 모델을 내려받고, 그동안은 온라인 번역을 쓴다.
- 모바일·그 외: 무료 온라인 번역(Google 비공식 무료 주소). 아래 상태줄에 지금 엔진이 표시된다.
- 음성인식은 크롬 기본 기능이라 음성이 Google 서버로 전송된다.

## 언어 추가

`app.js` 맨 위 `LANGS`에 한 줄 추가: `{ id: 'nl', name: 'Nederlands', stt: 'nl-NL' }`

## 직접 테스트 체크리스트

- [ ] PC 크롬 · 듣기 · 마이크: 영어로 말하면 한국어 자막이 뜬다
- [ ] PC 크롬 · 듣기 · PC 소리: 유튜브 영어 영상 탭을 공유하면 자막이 뜬다
- [ ] PC 크롬 · 통화: 상대(영어)와 내 말(한국어)이 왼쪽/오른쪽으로 나뉘어 뜬다 (또는 Space 방식 안내가 뜬다)
- [ ] 상태줄 엔진이 잠시 뒤 '기기 내'로 바뀐다
- [ ] 휴대폰 · 듣기 / 대화: 마이크 허용 후 자막이 뜨고 화면이 꺼지지 않는다
- [ ] 아이폰 사파리 · 듣기: 영어로 몇 문장 말하면 문장마다 끊겨서 번역된다, 끊기면 "탭해서 계속 듣기"로 이어진다

## 데모

`http://localhost:5173/?demo=1` — 마이크 없이 예문으로 화면과 번역을 확인.

## 한계

- 통화 모드·PC 소리는 PC 크롬 전용 (모바일 브라우저는 다른 앱 소리를 못 받음).
- 스피커로 들으면 마이크가 상대 소리까지 받아 잘못 적을 수 있다 → 헤드폰 권장.
- 아이폰은 사파리에서만 음성인식이 된다. 안드로이드는 크롬.
- 말하는 언어 자동 감지는 안 된다 (브라우저가 음성인식기를 한 번에 하나만 돌릴 수 있음). 대화 모드에서 버튼/Space로 전환.
- 무료 온라인 번역은 비공식이라 막히거나 느려질 수 있다.
